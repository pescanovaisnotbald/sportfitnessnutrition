# Sport Fitness Nutrition — Redesign Concept

Front-end UX/UI redesign concept for [sportfitnessnutrition.com](https://sportfitnessnutrition.com/), a Spanish sports-nutrition and fitness-supplement retailer based in Terrassa, Barcelona.

Static single-page concept (`index.html`) built with Tailwind CSS (Play CDN) and vanilla JS — no build step required.

## What's inside

- Marquee announcement bar
- Sticky nav with scroll-aware blur + auto-hide
- Hero with an animated "nutrition label" motif
- Category pill navigator
- Best-seller product grid with hover nutrition quick-view, flavor/size selectors, and animated add-to-cart
- Trust & authority section
- Multi-column footer with newsletter signup
- Slide-over cart drawer with a live free-shipping progress bar
- Full light/dark theme support (toggle in the nav)

## Local preview

Just open `index.html` in a browser — no build step needed.

## Deploy

Deployed on Vercel as a static site (no framework, no build command).
